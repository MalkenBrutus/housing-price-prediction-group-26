## Files

- `Assignment_1_Housing_Price_Prediction.ipynb`: code, plots and results
- `AmesHousing.csv`: the dataset from the assignment

## Run the notebook

Keep the CSV and notebook in the same folder. Install the packages below, then open the notebook and run the cells in order.

```bash
python -m pip install -r requirements.txt
jupyter notebook Assignment_1_Housing_Price_Prediction.ipynb
```
