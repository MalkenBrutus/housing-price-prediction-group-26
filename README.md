# Housing Price Prediction — Group 26

Assignment 1 using the supplied Ames Housing dataset. The notebook explores the data, creates an 80/20 training and test split, prepares the features, and compares linear regression, a decision tree, and a random forest using test RMSE and R².

**Group:** Matteo Castelli, Haakon Torvik Gullbekk, Marius Alexander Langaas Klæbo, Jørund Birkeland.

## Files

- `Assignment_1_Housing_Price_Prediction.ipynb` — analysis, figures, explanations, and results.
- `AmesHousing.csv` — the dataset supplied for the assignment.

## Run

Install Python 3 and Jupyter, then install the packages in `requirements.txt`. Open the notebook from this folder and run the cells in order. The CSV should stay in the same folder as the notebook.

```bash
python -m pip install -r requirements.txt
jupyter notebook Assignment_1_Housing_Price_Prediction.ipynb
```
